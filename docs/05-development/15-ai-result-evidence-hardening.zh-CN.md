# AI 路由与结果真实性加固

## 审查结论（2026-09-08）

封面请求的意图解析超时后返回空对象，词法路由没有识别写请求，最终进入 general 并输出无凭据的成功描述。数据库没有对应草稿或 Item.image 更新，不是已经写入但图片刷新失败。

共用风险：空/低置信度结果继续降级；write_intent_requires_clarification 未在 Chat 入口拒绝；固定场景和 Agent 就绪分支未共享动作门禁；SSE 原文先发后审；流式 delta 与 completed.message 可不一致。影响不局限商品图片，也涉及订单、库存及未支持的付款、取消等请求。

已存在的保护：四类草稿有动作契约与确认边界；生命周期计划有权限、版本、引用预检、事务和持久回执。聊天完成、草稿生成、图片暂存都不是正式业务执行证据。商品封面赋值复用上传/草稿/确认流程；生成或重绘新图片是另一种能力，不能用文本成功描述代替图片产物。

额外核查 `media_service.replace_item_image`：先上传再 Item.save，保存异常会清理新文件并抛出，不进入替换成功返回；upload_item_image 只表示文件上传。`execute_ai_draft_v1` 要求正式 target_name 后才记录 execution，异常回滚并记录失败；`product_lifecycle_plan_service` 保留独立持久回执及重放。未发现这些入口与本次截图相同的“仅模型文字即成功”路径，但这不是文件系统/数据库跨资源事务、并发或所有业务接口的完整认证。

## 方案

1. **入口失败关闭**：意图解析配置/网络/契约错误返回稳定错误码；空、未知或非有限/低置信度结果不得由本地词法取得路由授权。自动入口、缓存复用、固定场景、重试及 Agent 模式共享只读 Chat 门禁，写请求回到专用草稿/计划入口。现有确定性业务页面不受影响。取舍：解析服务故障时只读聊天也需重试，不能同时承诺降级可用和未知意图安全。
2. **输出纵深防护**：Backend 公共 Chat 出口检查无执行凭据的典型完成断言；SSE 缓存完整回答，检查成功后再发布正文，进度/工具事件继续发送；限制缓存大小。同步、流式、恢复均不得只检查最终消息却提前泄漏 delta。持久化和最终事件使用同一正文。词法断言检查只是补充，不能证明任意自然语言都没有幻觉。
3. **证据状态分离（后续）**：统一服务端 operation receipt（动作、目标、提交版本、结果、产物、持久 ID）；UI 分别显示回答完成、草稿待确认、预检阻断、执行失败、正式执行成功。模型字段不能充当回执。完整输出采用受控结果块，写结果由回执模板生成；普通解释文字仍需语义评测。
4. **可恢复澄清（后续）**：区分封面赋值与重绘意图，提供明确选择；解析失败重试保留原文/附件，不改成普通聊天；加入解析阶段独立可观察记录、能力拒绝率和无凭据断言率。

## 本轮范围与验证

本轮落实入口门禁、公共输出防护和回归；不新增图片生成工具、不自动执行图片替换、不更改付款/库存等领域写接口、不修补历史会话数据。Backend 防护覆盖经其公开入口的同步/异步 Provider 结果；独立 Orchestrator 内部调用仍需另行收敛，不能声明全系统所有出口均有相同策略。

回归应包含图片原句、各业务写动作、空/低置信度/非法置信度、缓存与固定场景、SSE 跨 chunk 断言、最终正文不一致、合法查询及历史状态陈述。具体运行结果在当前交接记录；未运行的 HTTP/浏览器/真实 Provider 验收不得写为通过。
